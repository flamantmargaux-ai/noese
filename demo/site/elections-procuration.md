# Voter par procuration
Faites votre demande en ligne sur maprocuration.gouv.fr, puis faites-la valider dans un commissariat, une gendarmerie ou un consulat.
Le mandataire vote dans le bureau de vote de la personne qui lui donne procuration. Il doit être inscrit sur les listes électorales, mais pas forcément dans la même commune.
Faites la démarche le plus tôt possible avant le scrutin.
